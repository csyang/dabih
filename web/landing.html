Capabilities
What Dabih Does
◈
Structural Symmetry Detection
Parse-only RTL analysis via pyslang CST — no elaboration required. Works on partial and dirty source trees.
⬡
Three Analytic Methods
Pólya closed-form for Sₙ. Burnside's lemma for partial symmetry groups. Möbius inversion as documented fallback.
⧖
Partial Symmetry API
Declare instance-level symmetry without thinking about coverpoint indices. Three ergonomic methods for Sₖ, Zₙ, and Z₂×Z₂.
◎
Coverage Expansion
Any hit bin implies its entire orbit. Merge across simulation runs. Canonical-form expansion for large spaces.
⊞
Simulator Agnostic
Portable JSON coverage format. Emittable from UVM with $fwrite. No EDA toolchain APIs required.
◌
Holes Reporting
Identify uncovered equivalence classes. Per-run attribution. Rich HTML report for sign-off review.
Quick Start
From RTL to Compressed Coverage
python 
# 1. Extract generate-for arrays from RTL
from dabih import RtlExtractor, BinSpaceBuilder, CoverSpec
from dabih import CoverageResult, SymbolicExpansionEngine
from dabih.reporting import render_html_report

ext = (RtlExtractor()
       .add_file("examples/rtl/serdes_top.sv")
       .add_param("N_LANES", 8))

# 2. Build compressed coverage model — 65,536 → 165 bins
results = (BinSpaceBuilder(ext.extract())
           .cover("state", ["IDLE", "ACTIVE", "STALL", "ERROR"],
                  module_type="rx_lane")
           .build(ext.param_overrides))

bs = results[0].bin_space   # 165 orbit representatives

# 3. After simulation: load results and expand
cr  = CoverageResult.from_file("sim_run_042.json")
er  = SymbolicExpansionEngine(bs).expand(cr)

print(er.class_coverage_pct())   # → 87.3%
print(er.is_complete())           # → False

# 4. Generate HTML sign-off report
render_html_report(er, title="SerDes RX Coverage",
                   path="coverage_report.html")
